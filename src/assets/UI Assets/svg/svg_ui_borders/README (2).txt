Notes:
- All files use a 1000 x 1000 viewBox and transparent backgrounds (except the wobbly rounded rectangle, which includes a cream fill).
- They are regular SVG files intended to scale cleanly.
- You can import them directly, or open and tweak stroke widths / colors.
- Suggested React Native usage: react-native-svg and react-native-svg-transformer.
